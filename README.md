# Sanidad.exe: guía básica de IA para profesionales de la salud

Guía básica de inteligencia artificial para profesionales de la salud, creada con eXeLearning.

> **EN** · Basic guide to artificial intelligence for healthcare professionals, built with eXeLearning.

🔗 **Demo:** [sanidad.exe.sanidadedtech.es](https://sanidad.exe.sanidadedtech.es/)

## Para quién es

Profesionales sanitarios.

## Qué incluye

- Introducción a la IA aplicada a la salud

## Tecnología

- Recurso creado con [eXeLearning](https://exelearning.net/) y exportado como sitio web.
- Las librerías de la carpeta `libs/` son de terceros y mantienen sus propias licencias.
- Publicado con GitHub Pages.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
